# 🔧 Настройка GigaChat API

## Получение credentials

1. **Регистрация на SberDevices:**
   - Перейдите на https://developers.sber.ru/
   - Зарегистрируйтесь или войдите в аккаунт

2. **Создание проекта:**
   - Нажмите "Создать проект"
   - Заполните название проекта (например, "CommentParser")
   - Выберите тип проекта: "Веб-приложение"

3. **Получение API ключей:**
   - В настройках проекта найдите раздел "API ключи"
   - Нажмите "Создать новый ключ"
   - Выберите сервис "GigaChat"
   - Скопируйте `client_id` и `client_secret`

4. **Обновление конфигурации:**
   - Откройте файл `.env` в корне проекта
   - Замените заглушки на реальные значения:
   ```env
   GIGACHAT_CLIENT_ID=ваш_реальный_client_id
   GIGACHAT_CLIENT_SECRET=ваш_реальный_client_secret
   ```

## Тестирование

## Возможные проблемы

### Ошибка "Can't decode 'Authorization' header"
- Проверьте правильность `client_id` и `client_secret`
- Убедитесь, что credentials не содержат лишних пробелов
- Проверьте, что используете реальные credentials, а не заглушки

### Ошибка "Access denied"
- Убедитесь, что у вас есть доступ к GigaChat API
- Возможно, потребуется подтверждение доступа от администратора

### Ошибка "Invalid scope"
- Проверьте, что scope установлен как `GIGACHAT_API_PERS`
