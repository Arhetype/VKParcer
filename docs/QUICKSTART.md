# 🚀 БЫСТРЫЙ СТАРТ

## 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

## 2. Настройка конфигурации
Создайте файл `.env` на основе `env_example.txt`:
```bash
cp env_example.txt .env
```

Заполните `.env` своими данными:
```env
VK_ACCESS_TOKEN=ваш_токен_вк
GIGACHAT_CLIENT_ID=ваш_client_id
GIGACHAT_CLIENT_SECRET=ваш_client_secret
```

## 3. Получение токенов

### VK Token
1. Идите на https://vk.com/apps?act=manage
2. Создайте Standalone-приложение
3. Перейдите по ссылке: `https://oauth.vk.com/authorize?client_id=YOUR_APP_ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=video&response_type=token&v=5.131`
4. Скопируйте `access_token` из адресной строки

### GigaChat API
1. Регистрируйтесь на https://developers.sber.ru/
2. Создайте проект и получите credentials

## 4. Запуск

### Интерактивный режим (рекомендуется)
```bash
python run.py
```

### Командная строка
```bash
python main.py "https://vk.com/video123456_789"
```

### Просмотр результатов
```bash
python view_results.py history
```
