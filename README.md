# Парсер комментариев ВК с анализом через GigaChat

Современный парсер комментариев ВКонтакте с анализом настроения аудитории через GigaChat API. Проект построен с использованием чистой архитектуры и принципов SOLID.

## 🏗️ Архитектура

Проект организован в виде модульной архитектуры с четким разделением ответственности:

```
src/
├── core/           # Основные классы и конфигурация
│   ├── base.py     # Базовые классы и интерфейсы
│   ├── config.py   # Конфигурация приложения
│   └── manager.py  # Основной менеджер приложения
├── parsers/        # Парсеры данных
│   └── vk_parser.py # Парсер ВКонтакте
├── analyzers/      # Анализаторы
│   └── gigachat_analyzer.py # Анализатор GigaChat
├── database/       # Работа с базой данных
│   └── manager.py  # Менеджер БД
├── cli/           # Интерфейсы командной строки
│   ├── main.py    # Основной CLI
│   └── interactive.py # Интерактивный режим
└── utils/         # Утилиты
    └── helpers.py  # Вспомогательные функции
```

## 🚀 Возможности

- 🔍 **Парсинг комментариев ВК** - получение комментариев к любым видео
- 🤖 **Анализ через GigaChat** - определение настроения аудитории
- 📊 **Детальная аналитика** - сильные/слабые стороны, рекомендации
- 💾 **Сохранение в SQLite** - все данные сохраняются локально
- 📈 **История анализов** - просмотр предыдущих результатов
- 🎯 **Модульная архитектура** - легко расширяемый код
- 🔧 **Гибкая конфигурация** - настройка через переменные окружения

3. **Настройте конфигурацию:**


## ⚙️ Настройка

### VK API Token

1. Перейдите на https://vk.com/apps?act=manage
2. Создайте Standalone-приложение
3. Получите токен доступа с правами `video`
4. Добавьте в `.env`:
```env
VK_ACCESS_TOKEN=your_vk_token
```

### GigaChat API

1. Зарегистрируйтесь на https://developers.sber.ru/
2. Создайте проект и получите API ключи
3. Добавьте в `.env`:
```env
GIGACHAT_CLIENT_ID=your_client_id
GIGACHAT_CLIENT_SECRET=your_client_secret
```

## 🎯 Использование

### Командная строка

```bash
# Анализ видео
python main.py "https://vkvideo.ru/video-190452322_456239102"

# С ограничением комментариев
python main.py "https://vk.com/video123456_789" --max-comments 500

# Просмотр статистики
python main.py --stats

# История анализов
python main.py --history
```

### Интерактивный режим

```bash
python run.py
```

### Программный интерфейс

```python
from src.core.manager import CommentAnalyzer

analyzer = CommentAnalyzer()
analyzer.initialize()

result = analyzer.analyze_video_comments("https://vk.com/video123456_789")
analyzer.print_analysis_report(result)
```

## 🤝 Разработка

### Структура проекта

- **Core** - базовые классы и интерфейсы
- **Parsers** - модули для парсинга данных
- **Analyzers** - анализаторы контента
- **Database** - работа с данными
- **CLI** - интерфейсы пользователя
- **Utils** - вспомогательные функции

### Принципы

- **SOLID** - принципы объектно-ориентированного программирования
- **DRY** - не повторяйся
- **KISS** - простота и ясность
- **Separation of Concerns** - разделение ответственности
